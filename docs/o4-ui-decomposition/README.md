## Що вже видно

**KR4.4 — найцінніший.** `MultiStepForm.tsx` збирає до 11 кроків рантаймом, послідовністю
`if`-ів по `dynamicSteps.push(...)`: раса → деталі раси → опції раси → клас → підклас → опції
підкласу → опції класу → додаткові риси → … → риса → опції риси → риса походження → експертиза →
мови. Набір кроків комбінаторний, і саме звідти приходить більшість скарг.

Описати це таблицею («крок X показується, якщо виконано умову Y») означає зробити набір кроків
даними — а дані можна протестувати без рендеру взагалі.

**KR4.3 треба міряти до, а не після.** Прогнати `jscpd` на початку O4 і записати число. Без
базової цифри «звели дублікати» — це відчуття, а не результат.
