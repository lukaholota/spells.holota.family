# KR2.1 — Матриця білдів

**Ціль:** [O2](README.md) · **Статус:** ☐ не розпочато · **Залежить від:** KR1.3

## Навіщо

Golden-тести варті рівно стільки, скільки покриває набір вхідних даних. Треба свідомо обраний
набір білдів, який зачіпає кожну гілку логіки створення персонажа — а не «десяток тих, що першими
спали на думку».

## Готово, коли

- [ ] `tests/fixtures/builds/` — кожен білд це файл із валідним `PersFormData`
- [ ] покрито всі осі з таблиці нижче
- [ ] кожен білд має коментар-рядок: **чому саме він у наборі**, яку гілку тримає
- [ ] набір проганяється через `createCharacter` без помилок (сам результат — KR2.2)

## Осі покриття

Мінімум по одному білду на кожне значення. Комбінувати осі, де вони взаємодіють.

| Вісь | Значення |
|---|---|
| Клас | всі 12 базових |
| Тип кастера | повний, половинний, третинний, пактовий, некастер |
| Підклас | береться на 1, 2, 3 рівні (залежить від класу — 2014!) |
| Система ASI | `POINT_BUY`, `SIMPLE`, `CUSTOM` |
| Раса | з фіксованим ASI, з ASI на вибір (Tasha), з підрасою, з варіантом раси |
| Варіант раси | `overridesRaceASI` виставлений і ні |
| Підраса | `replacesASI` виставлений і ні |
| Походження | з рисою і без |
| Риса | без риси, `Variant Human`, риса з вибором (Resilient, Skill Expert, Fighting Initiate) |
| Опції класу | клас з `ClassChoiceOption` і без |
| Мультиклас | 0 (одноклас), 2 класи, 3 класи, комбінація кастерів різного типу |
| Експертиза | є / немає |
| Мови | вибір є / немає |

## Особливі випадки, які треба покрити явно

Це місця, де за словами власника вже щось ламалось або де логіка найзаплутаніша:

- **Warforged** — статичний AC-бонус раси, який ініціалізується в 0 і вмикається тумблером
  (`initialRaceStaticAcBonus` у `createCharacter`)
- **Мультикласові слоти заклинань** — повний + пактовий разом (Wizard/Warlock)
- **Four Elements Monk** — дисципліни, згадані окремо в історії комітів як проблемні
- **Артифайсер + інфузії** — окремі сіди `infusionSeed`, `infusionFeaturesSeed`
- Найдовший можливий шлях у конструкторі — раса з варіантом і підрасою + клас з підкласом і
  опціями + походження з рисою + риса з вибором + експертиза + мови (~11 кроків)

## Як обирати

Не намагатись покрити декартів добуток — це тисячі комбінацій. Мета — щоб **кожна гілка
`if`-а** в `createCharacter` виконалась хоч раз. Практичний спосіб: увімкнути покриття
(`vitest --coverage`) на `src/lib/actions/character.ts` і додавати білди, доки не перестануть
з'являтися нові рядки.
